# Uzum Market — лидогенерация в Telegram

Бот-воронка: опрос (язык → имя → продавец? → возраст → телефон) → заявка админу →
меню лид-магнитов с проверкой подписки на целевую группу.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # впишите BOT_TOKEN
python main.py
```

## Обязательно перед стартом

1. **Токен.** В `.env` вставьте токен от @BotFather. Если токен попадал в чат/репозиторий — отзовите его
   (`/revoke` в @BotFather) и используйте новый.
2. **Добавьте бота в целевую группу администратором** — иначе `get_chat_member` не сработает и бот
   будет отвечать «не удалось проверить подписку».
3. **Откройте бота с аккаунта админа и нажмите `/start`** — иначе Telegram не даст боту написать вам заявки.
4. `TARGET_GROUP_ID` — числовой ID группы (`-100…`), `TARGET_GROUP_LINK` — пригласительная ссылка.

## Метки трафика

Ссылки вида `https://t.me/<бот>?start=instagram` (`facebook`, `shorts`, `linkedin`, `threads`…).
Метка сохраняется при первом контакте и приходит в заявке. Допустимы латиница, цифры, `_` и `-`.

## Админ-команды (только `ADMIN_ID`)

- `/stats` — сколько запустили/прошли опрос, по источникам
- `/export` — CSV со всеми анкетами

## Как добавить продукт

В `config.py` в словарь `PRODUCTS` добавьте запись (кнопка, текст, ссылка, PDF). Положите PDF в `materials/`.
Меню, проверка подписки и выдача подхватят его автоматически.

Сейчас в `materials/` лежат PDF-заглушки (пересоздать: `python make_placeholders.py`) —
замените их своими файлами с теми же именами, а ссылки-заглушки `example.com` в `config.py` — настоящими.

## Структура

```
main.py  config.py  database.py  states.py  keyboards.py  texts.py
handlers/ start.py  survey.py  menu.py  admin.py
materials/  (PDF)
```

FSM хранится в памяти: после перезапуска бота пользователь, не дошедший до конца опроса, просто
нажимает `/start` заново. Анкеты хранятся в SQLite (`bot.db`).
